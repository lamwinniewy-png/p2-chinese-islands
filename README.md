# 蘇蘇晴晴的漂浮魔法島 – 二年級中文科溫習

iPad 互動溫習網站（繁體中文．粵語朗讀）。評估範圍：中書／中作 二上第一冊第一、四、八、十二、十四課；中練 練習二、三、五、十、十九及已有知識。

功能：課文朗讀、字詞卡、筆順魔法（Hanzi Writer）、翻翻記憶卡、魔法鍋分類、學習重點、每島 10 題挑戰、閱讀雲朵、模擬評估、聽詞語挑戰、錯題本、貼紙簿。

## 詞語星星島（新關卡）

40 個評估詞語分成 8 個星星站，每站有四步：① 讀一讀、② 寫一寫（有描紅）、③ 考一考、④ 聽寫挑戰（沒有描紅）。完成關卡可以收集兩本貼紙簿：「詞語星星貼紙簿」和「魔法島成就貼紙簿」，一共 32 張貼紙。
